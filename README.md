Atlantic AI

Overview

Atlantic AI is a personal AI learning assistant designed to help students interact with their learning materials and ask questions about academic topics.

The project combines Python, local document processing, conversation history, prompt engineering, and a locally running large language model to generate responses.

Features

- AI-powered question answering: Ask questions and receive answers generated by a local language model.
- Local document processing: Extract text from PDF documents and use relevant information to answer questions.
- Conversation history: Keep track of previous questions and AI responses during a session.
- Prompt engineering: Organize instructions, document information, conversation history, and user questions into a prompt.
- Streamlit interface: Interact with the assistant through a simple web application.
- Local language model: Use Ollama to run the Llama 3.2 model locally.

Technologies Used

- Python
- Streamlit
- Ollama
- Llama 3.2
- Requests
- PyMuPDF ("pymupdf") for PDF text extraction

How It Works

1. The user enters a question through the Streamlit interface.
2. The application retrieves relevant information from the available document.
3. Previous conversation messages are retrieved when available.
4. The prompt module combines the information, conversation history, and current question.
5. The chatbot sends the prompt to the locally running Ollama model.
6. The generated response is returned to the application and displayed to the user.
7. The question and response can be stored in the conversation history.

Installation and Setup

Prerequisites

- Python installed on your computer.
- Ollama installed and running.
- The Llama 3.2 model downloaded through Ollama.

1. Clone or download the project

Open a terminal in the project directory.

2. Install Python dependencies

python -m pip install -r requirements.txt

3. Download the language model

ollama pull llama3.2

4. Start Ollama

Make sure the Ollama application or service is running.

5. Run Atlantic AI

python -m streamlit run app.py

Streamlit will provide a local URL that you can open in your browser.
